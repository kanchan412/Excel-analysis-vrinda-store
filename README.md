# Excel Analysis – Vrinda Store

A complete Excel-based sales analysis project for Vrinda Store using dashboards, pivot tables, charts, and data cleaning techniques to generate business insights from raw sales data.

## 🚀 Project Overview

This project focuses on analyzing Vrinda Store sales data using Microsoft Excel.
The goal is to transform raw business data into meaningful insights that help understand:

* Sales performance
* Customer behavior
* Top-selling categories
* Regional performance
* Monthly trends
* Order status analysis

The project demonstrates practical data analysis and dashboard creation skills using Excel.

## 📊 Features

* Data Cleaning & Processing
* Pivot Tables
